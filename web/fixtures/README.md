# UI fixtures

Example API responses for the front end. Shapes are in `docs/API_CONTRACT.md`. With `VITE_USE_FIXTURES=true`, `web/src/api.ts` reads these files instead of calling the API.

Generated by `scripts/export_ui_fixtures.py` from real runs (`p4-CS-S1`, `p4-CS-S3`), the B2-k baseline scorecards and `runs/leaderboard.csv`. Do not edit by hand: change the script and run it again. Phase 5 and later update them.

| File | Serves | Notes |
| --- | --- | --- |
| `health.json` | `GET /api/health` | |
| `scenarios.json` | `GET /api/scenarios` | All 27 scenarios. Only `customer_service` is available. |
| `run.CS-S1.json`, `run.CS-S3.json` | `GET /api/runs/{id}` | `redact` is `pending`: not built yet. |
| `stage.profile.json`, `stage.detect.json` | stages `profile`, `detect` | Same for both scenarios. |
| `findings.json` | findings panel | The three real findings, from other datasets. `customer_service` has none. |
| `plan.CS-S1.json`, `plan.CS-S3.json` | stage `plan` | For the compare view. |
| `stage.transform.*.json` | stage `transform` | |
| `scorecard.ours.*.json`, `scorecard.b2k.*.json` | the two scorecards of stage `verify` | Same scenario, same scorer. Paths replaced by labels. |
| `stage.verify.*.json` | stage `verify` | Scorecards, gate, k, residual risks, ablation. |
| `stage.redact.CS-S1.json`, `.CS-S3.json` | stage `redact` | 20 synthetic turns, `spans` empty until Phase 5. CS-S3 withholds the transcripts. |
| `stage.report.*.json` | stage `report` | Plan table as Markdown. `policy_card` is `null`. |
| `leaderboard.json` | leaderboard rows | |

Placeholders, computed by the script and not yet produced by the pipeline: `gate` (limit 0.02 per risk component, k at least 5), `residual_risks`, `k`, and the empty `ablation`, `spans` and `per_label`.

CS-S1 currently fails the gate because the transcripts are released unredacted (free-text identifier leakage 1.00). CS-S3 passes. After Phase 5 the CS-S1 numbers change; the UI reads them from the data.

No keys, row maps or local paths are in these files. `tests/test_ui_fixtures.py` checks that.

Synthetic data: "TrustED PETs Proving Ground 2026, synthetic data by Since AI ry (CC BY 4.0)". Do not log the turn text.
